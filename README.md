# aviation-coursework-1

**Авиационный трекер** — курсовая работа на Python. Проект получает данные о самолётах, находящихся в воздухе, с открытого API OpenSky Network и сохраняет их в базу данных PostgreSQL. Реализована аналитика по странам и скоростям полётов.

## Функционал

* Получение координат стран через Nominatim (для формирования зон мониторинга).
* Запрос текущих состояний самолётов в заданной географической области через API OpenSky (`/states/all`).
* Сохранение данных в PostgreSQL:
  * таблица `countries` (страны и их координаты; загружено минимум 10 стран).
  * таблица `airplanes` (текущие данные о бортах: ICAO24, позывной, страна, скорость, координаты, статусы).
* Аналитические методы класса `DBManager`:
  * `get_countries_and_aeroplanes_count()` — количество самолётов по странам (с использованием JOIN).
  * `get_avg_speed()` — средняя скорость всех самолётов.
  * `get_aeroplanes_with_higher_speed()` — список самолётов со скоростью выше средней.
  * `get_aeroplanes_with_keyword()` — поиск по подстроке в позывном (частичное совпадение).
  * `get_all_aeroplanes()` — полный список всех воздушных судов.
